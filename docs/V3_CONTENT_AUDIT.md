日期：2026-09-12
方法：逐个 Scene、共享组件、页尾与 noscript 文案检查；标签只描述编辑动作，不改变数据事实。

## 审计标签

- `[KEEP]`：事实边界、来源定位或有效叙事保留。
- `[REWRITE]`：保留事实，重写成更具体、更像编辑现场的句子。
- `[DELETE]`：删除重复总结、装饰性过渡或没有信息量的句子。
- `[MOVE]`：移动到更适合的 Scene、Source Drawer 或 caption。
- `[NEEDS SOURCE]`：当前材料不足，不写成事实或统计。

## AI 模板化语言检查

在 `src`、`content.txt`、`index.html` 和 `docs` 的主要正文中未检出规范列出的“值得注意的是 / 与此同时 / 进一步来看 / 可以发现 / 这表明 / 由此可见”等固定过渡词。当前更大的模板风险不是单句，而是重复的“标题 + intro + 容器 + 图表 + caption”结构，因此优先通过 Scene 节奏和材料身份解决。

## 内容执行红线

- 不新增统计数字、比例、政策数据、人物或采访。
- 不把 77 家写成全国总数，不把 282 写成全国人口，不把安吉青年写成数字游民人数。
- 不把 `reported`、`target`、`pending` 改成无状态的完成结果。
- 不让图表重复解释同一段正文；图表旁只保留 takeaway、annotation 和限制条件。
