# 数字江河 V2.1｜来源台账

更新时间：2026-09-12

本台账与 `src/data/evidence.ts` 一一对应。页面可以使用“报道”或“目标”，但必须保留状态；`pending` 不得进入主线结论。

## 来源分级

| 等级 | 本项目用法 |
|---|---|
| A1 | 政府正式文件、政府官网统计：措施、目标、政府公布进展 |
| A2 | 新华社、人民网、中央/省级主流媒体：人物、场景、地点、报道数字 |
| A3 | 学术期刊、人民论坛正式研究：样本统计、理论与结构性分析 |
| B1 | 行业或社区原创调查：只描述有限样本，不外推全国 |
| C | 社区官网、自媒体：只作线索与二次核验入口 |

## 主线来源

1. [NCC《全景式数字游民洞察报告》公开预览](https://www.fxbaogao.com/detail/4614525)：仅支持 2024 年社区渠道样本方法与构成；原图未纳入仓库，画像字段不进入 V2.1 主线。
2. [新华网转载中国青年报报道](https://www.news.cn/2023-03/23/c_1129456154.htm)：安吉 DNA 社区行动案例。
3. [《人民论坛》：中国数字游民社区的发展演进调查](https://paper.people.com.cn/rmlt/pc/content/202607/20/content_30178497.html)：77 家研究样本、区位、类型与规模结构。
4. [新华社：引导数字游民更好参与乡村振兴](https://www3.xinhuanet.com/politics/20250327/cb9de601c22e44c59843ab96124b30f8/c.html)：黄山黟县社区行动案例。
5. [新华社：浙江安吉青年入乡新观察](https://www.xinhuanet.com/20250208/e67b874a40c0474a825fed82f95d623c/c.html)：安吉青年入乡生态，统一使用 `youth-rural-employment` scope。
6. [大黄山全球数字游民集聚创业地建设行动方案](https://www.cnjx.gov.cn/OpennessContent/show/3392059.html)：黄山政策目标，只能标为 `target`。
7. [丽水市支持数字游民旅居共创十条措施](https://tradeinservices.mofcom.gov.cn/article/szmy/hydt/202512/180554.html)：丽水政策与公开进展，状态为 `reported`。

## 使用红线

- NCC 的 282 只表示社区渠道样本，不能写成全国人口。
- 77 只表示研究纳入的正常运营社区，不能写成“全国共有 77 家”。
- 安吉青年大学生入乡数字统一为 `youth-rural-employment`，不能写成数字游民人数。
- 黄山行动方案中的 2027/2030 数字是政策目标，不是完成结果。
- 经纬度只用于可验证案例定位；不生成全国社区逐点分布。
