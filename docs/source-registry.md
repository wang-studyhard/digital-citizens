# 数字江河 V2.1｜来源台账

更新时间：2026-09-12

本台账与 `src/data/evidence.ts` 一一对应。页面可以使用“报道”或“目标”，但必须保留状态；`pending` 不得进入主线结论。

## 来源分级

| 等级 | 本项目用法 |
|---|---|
| A1 | 政府正式文件、政府官网统计：措施、目标、政府公布进展 |
| A2 | 新华社、人民网、中央/省级主流媒体：人物、场景、地点、报道数字 |
| A3 | 学术期刊、人民论坛正式研究：样本统计、理论与结构性分析 |
| B1 | 行业或社区原创调查：只描述有限样本，不外推全国 |
| C | 社区官网、自媒体：只作线索与二次核验入口 |

## 使用红线

- NCC 的 282 只表示社区渠道样本，不能写成全国人口。
- 77 只表示研究纳入的正常运营社区，不能写成“全国共有 77 家”。
- 安吉青年大学生入乡数字统一为 `youth-rural-employment`，不能写成数字游民人数。
- 黄山行动方案中的 2027/2030 数字是政策目标，不是完成结果。
- 经纬度只用于可验证案例定位；不生成全国社区逐点分布。
- 外部图片只使用已登记的人工筛选素材；来源、原图链接、图注、摄影署名与用户授权状态见 [`public/media/manifest.json`](../public/media/manifest.json)。
