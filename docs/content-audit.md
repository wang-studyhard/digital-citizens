# 数字江河 V3｜内容审计

更新时间：2026-09-12

## 审计结论

V3 主线已按“研究台账 × 地方现场”重组。数字统一从 `src/data/evidence.ts` 读取；`src/data/derived.ts` 只保存由证据 ID 组合出的图表视图、步骤与表格，不新增未经登记的事实。来源抽屉可回到 16 条参考资料及方法说明。

## 已纳入主线

- NCC：827 回收、798 有效、282 数字游民样本、516 探索者样本、8 名结构化访谈对象；仅描述社区渠道样本。
- 77 家研究样本：截至 2025-12-31，含 52/13/12 区位结构、四类功能结构、68/9 规模结构；不写成官方普查。
- NCC 年龄、学历、性别：以 282 样本口径显示为横向条形图、约数与移动端表格，不伪造个体级明细。
- 安吉：空间整合、青年入乡与青创项目数据；青年数据统一为 `youth-rural-employment`。
- 黄山/黟县：58 个房间、约 500 人旅居案例；相关 2027 数字统一为政策目标。
- 丽水：2025/2026 公开报道中的社区、提案与落地进展；保持 `reported`，不写成长期效果。

## 状态分离

| 状态 | 页面表达 | 审计规则 |
|---|---|---|
| `measure` | 措施 / 制度动作 | 说明已经发布或实施的政策动作，不自动推导成效。 |
| `reported` | 报道记录 | 明确归因于公开报道，不升级为独立评估。 |
| `target` | 目标至 2027 | 只作为目标展示，不能写成已经发生。 |
| `pending` | 暂不进主线 | 没有足够定位或口径不稳时保留待核。 |

## 图片与可访问性

- 3 张本地新华社报道图片登记在 `public/media/manifest.json`，包含自然尺寸、事实角色、审核状态和授权备注；页面不强裁图片，不以装饰图替代证据。
- 关键图表均有表格或移动端列表 fallback；菜单、来源抽屉、步骤切换和 CTA 使用原生按钮/`dialog`。
- 页面不依赖颜色单独传达状态；`measure`、`reported`、`target` 文字标签始终可见。
