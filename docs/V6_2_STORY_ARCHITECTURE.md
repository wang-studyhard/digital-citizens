## 合章规则与核验

- 原10章分别按1—2、3—4、5—7、8—9、10分组。只在主章显示01—05编号；原题保留为小标题，所有`scene0`至`scene12`锚点保持唯一可定位。
- 主章使用`h2`，章内引言使用`h3`；章内不再重复完整章节外壳及大幅上下留白。目录五个入口分别指向`scene1/4/7/10/12`。
- 原正文、证据值、来源链接和图形内容按合并前DOM快照逐项核对；唯一正文措辞调整是“上一章的问卷”改为“前面的问卷”。不合并数据分母、不改变因果判断。
- 本地`npm run verify`通过；六断点无页面及标题溢出，主章嵌套、旧锚点、桌面/手机目录跳转与来源键盘开关通过。结果在被忽略的`work/chapter-merge/results.json`，合并前基线和截图在同目录。未推送或部署。
