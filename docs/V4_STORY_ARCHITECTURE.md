# 数字江河 V4｜故事架构（已由 V6.2 取代）

> 当前 Batch 2 的生效结构见 `docs/V6_2_STORY_ARCHITECTURE.md`。下文保留为 V4 规划历史，不再作为页面实施依据。

状态：编辑结构冻结候选  
核心问题：当工作可以离开固定办公室，一群年轻人为什么开始移动，他们怎样工作、怎样生活，又怎样与新的地方产生关系？

## 1. 编辑承诺

这是一篇关于“关系如何形成”的数据新闻，不是数字游民生活方式广告，也不是地方政策成绩单。文章从一张移动中的工作桌开始，以一段关系能否持续结束；样本、社区和政策都服务于这条问题链。

读者读完应记住三件事：

1. 我们看到的是具体样本，不是全国人口画像。
2. 流动不等于不停旅行，也不自动带来自由、稳定或更高收入。
3. 真正值得观察的不是到访，而是人、社区和地方是否形成持续合作。

## 3. Prologue｜办公室消失以后

**Opening**  
清晨，一张电脑桌可能出现在城中公寓、县城老厂房或村里的共享空间。改变的先是工作地点；随后才是路线、邻居和一天的时间表。

**Evidence**  
827 份问卷进入清洗，留下 798 份有效回答；其中 282 人已把自己置于数字游民生活中，516 人仍在观察或准备，另有 8 名受访者参加结构化访谈。

**Interpretation**  
这是调查入口，不是人口估算。页面第一次出现数字时，读者同时看见它们如何被筛选和分组。

**Limitation**  
样本来自 NCC 社区渠道，不能代表全国所有远程工作者或青年。

**Transition**  
如果不先问“这些人是谁”，关于流动的想象很容易比证据跑得更快。

首屏主标题保留“数字江河”，副标题使用“中国数字游民如何工作、迁徙，又与地方发生关系”。首屏不展示完整研究台账，只留一条可进入“数据与来源”的次级入口。

## 4. Chapter 01｜他们是谁

**Opening**  
先从 282 人开始。不是“典型中国青年”，而是一个社区渠道里已经选择或正在实践这种生活的人群。

**Evidence**

- 样本链：827 → 798 → 282 / 516；
- 282 人的出生年代、学历与性别；
- 待原表通过后加入工作经验和数字游民经历；
- 职位层级若恢复，只属于 516 名探索者，作为侧栏比较。

**Interpretation**  
90 后在该样本中占多数，本科及以上比例较高，性别结构相对接近；这些是样本内部结构。工作经验与数字游民经历要并置，帮助读者区分“在职场多久”和“开始移动多久”。

**Limitation**  
不用“年轻、高学历”概括全国，更不把美国 MBO 的职业分布补进中国图表。

**Transition**  
画像告诉我们谁进入了这条河，但还没有回答他们究竟如何移动、如何工作。

文案规则：数字在正文里出现一次就够；图旁说明只补充“怎样读”，不重复整段结论。

## 5. Chapter 02｜为什么出发，又如何维持生活

**Opening**  
流动不是永远在路上。对很多人而言，它可能意味着在一个地方停留数月，也可能意味着尚未决定下一次何时出发。

**Evidence**

- 迁徙频率四项候选；
- 数字游民经历时长；
- 收入 × 数字游民经历 5×5 候选矩阵；
- 是否重新固定办公 × 是否考虑定居 3×3 候选矩阵；
- 已公开摘要支持的边际结论，可在候选矩阵未通过时单独使用。

**Interpretation**  
把“流动”拆成时间、收入与下一步选择，而不是浪漫化为自由。若收入矩阵通过核验，sticky 场景让经历时长向下推进，观察收入分布如何改变；它只描述关联，不暗示经历导致收入上升。

**Limitation**  
这一章有最多 `PENDING` 数据。任何原表未通过，整张图退出，文章用已核实摘要和文字缺口继续，不以旧代码为证。

**Transition**  
个人的移动要有落点。下一步从时间和收入缩放到承接这些人的社区。

## 6. Chapter 03｜流向哪里

**Opening**  
“去哪里”并不只是城市榜单。研究中的 77 家社区，是一组能被观察的承接空间：它们分布在乡村、城乡结合部和城市，也承担不同功能。

**Evidence**  
同一组 77 个节点按总量 → 2025 新增 → 城乡区位 → 功能类型 → 规模重排；随后只把已登记的安吉、黟县 / 黄山、丽水和大理作为案例点放上地图。

**Interpretation**  
节点变形让读者看见“同一批对象的不同切面”。地图只负责把后文案例放回地理位置，不宣称热点、排名或全国覆盖。

**Limitation**  
没有 77 行逐社区数据，因此不画 77 个真实坐标；四个点也不是“中国数字游民地图”。

**Transition**  
地图把地点标出来，真实关系要进入地点内部才能看见。

## 7. Chapter 04｜当流动进入一个地方

### 安吉

**Opening**  
在溪龙乡，数字游民社区不是凭空出现：闲置空间先被打开，青年工作网络和村庄需求才有了相遇的位置。

**Evidence**  
新华社照片；社区成员为餐厅设计海报、门头和菜单，制作《白茶原小报》；37,000㎡ 与 1,200+ 青年属于更广的青年入乡生态；2026 年 100 个乡村工位是计划，不是完成量。

**Interpretation**  
案例价值在于把“远程工作”翻译成可见的本地任务，而不是证明数字游民带来整体增收。

**Limitation**  
青年入乡人数不等于数字游民人数，具体项目不能外推为县域因果效果。

### 黟县

**Opening**  
旧酿酒工业遗址变成有 58 个房间的共居空间，旅居者在数周或数月的停留中参与分享、户外项目与乡村文化活动。

**Evidence**  
两张新华社照片；58 个房间；成立不到一年约 500 名旅居者；后续政府页面中的入住、活动、项目设计、任务和消费数据均按 `REPORTED` 呈现。

**Interpretation**  
第二处 sticky 以同一张空间照片为锚点，滚动加入“空间 → 人 → 活动 → 地方任务 → 后续报道”。数字是时间节点，不是成绩计分板。

**Limitation**  
入住不等于长期居住，消费额不能直接归因于某一机制，后续报道也不是独立效果评估。

**Transition**  
两个案例都指向同一个问题：短暂抵达之后，什么才算真正留下？

## 8. Chapter 05｜来到之后，留下了什么

**Opening**  
“留下”不一定先表现为定居。它也可能是一份菜单、一次共同活动、一项被交付的任务，或一段仍在继续的合作。

**Evidence**  
把安吉和黟县已核实的行动节点放入同一条关系路径：旅居 → 社区参与 → 项目 / 任务 → 合作 → 待观察的长期关系。

**Interpretation**  
这是一张编辑关系图，不是数据流量图。视觉上用带来源标记的节点和实线 / 虚线区分“已报道发生”和“仍需长期观察”。正文不再把“编辑关系图”当标题，而是自然解释观察框架。

**Limitation**  
路径不表示必然顺序，更不表示每位旅居者都会走到最后。

**Transition**  
当这些关系开始被地方制度注意，故事就从社区现场进入政策回应。

## 9. Chapter 06｜地方开始回应

**Opening**  
地方的回应并不同步：有的先提供空间和服务，有的发布共创计划，有的把目标写到 2027 与 2030。

**Evidence**  
丽水、安吉、大黄山、黟县按发布日期进入时间线；随后用地方矩阵比较服务、空间、项目支持、公开进展和未来目标。每条只允许 `ACTION`、`REPORTED`、`TARGET` 三类前台状态，对应后台更细证据状态。

**Interpretation**  
时间线回答“什么时候发生”，矩阵回答“用什么工具回应”。大黄山 2027 / 2030 数字始终紧贴“目标”字样。

**Limitation**  
政策出台不等于被使用，公开报道的进展不等于长期效果，地方之间也不能用不同口径的数字排名。

**Transition**  
政策可以搭桥，但一段关系是否持续，仍需回到人和地方共同经历的时间。

## 10. Epilogue｜流动最终留下什么

**Opening / Interpretation**  
移动本身并不困难，真正困难的是一段关系能否持续。到达让人与地方相遇，项目让双方开始合作；只有时间能回答这些关系是否会变成稳定工作、持续参与或新的生活选择。

**Evidence boundary**

- 入住 ≠ 长期居住；
- 到访 ≠ 就业；
- 项目 ≠ 长期结果。

这三句作为边注与尾注出现，不再独立做成“审计场景”。结尾回到首屏的工作桌和路线意象：桌上的东西少了，留下的是几条仍在延伸的关系线。

## 11. 全篇写作规约

- 用具体人、地点、动作和时间开段，不用“本章节将展示”。
- 每一小节最多一个核心结论；一段尽量不超过 100–140 个汉字。
- 前台不用 `population`、`scope`、`locator` 等后台字段名；它们留在图注和证据抽屉。
- “不能推出”只在最容易误读的地方出现一次，其余改成自然限制句。
- 不虚构人物、对白、现场气味或未报道的动机。
- 不把目标写成完成量，不把相关写成因果，不把案例写成全国趋势。
- 图表不能替正文说完一切；正文也不逐条朗读图表。
